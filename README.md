# StudioCut Souayah

Professional video editing and client delivery in one creator-friendly workspace.

- Local-first, browser-based, 100% free stack.
- Open source under the MIT license.
- Built phase by phase from the Master Specification in `docs/`.

## Status

Phase 0 — Product and technical proof. Nothing in this repository should be
treated as a working product yet.

## Scripts

- `npm run dev`        — start dev server
- `npm run build`      — production build
- `npm run typecheck`  — TypeScript check
- `npm run lint`       — ESLint
- `npm run test`       — unit tests
- `npm run verify`     — typecheck + lint + test + build
